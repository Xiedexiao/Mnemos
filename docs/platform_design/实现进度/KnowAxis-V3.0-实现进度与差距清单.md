# KnowAxis V3.0 实现进度与差距清单

对照文档：`docs/platform_design/调研/KnowAxis-企业级知识智能平台-完整功能设计V3.0.html`

本文件记录：**已完成**（本轮补齐）、**待完成**（尚未实现的功能块），以及每项的落点。
状态口径：

- **已实现** — 有可用的读写路径、权限守卫与测试。
- **部分** — 有真实代码，但比文档窄（缺前端、缺某个出口、或只在特定驱动下生效）。
- **未实现** — 没有对应代码。

---

## 一、本轮已完成

以下每一项都是"文档要求 vs 代码实际"的差距，且已在本仓库落地。

### 第 2 章 权限

| 事项 | 文档 | 落点 |
|---|---|---|
| ACL 在默认检索器被丢弃（越权召回） | §2.1 权限先行 | `repository/retriever/postgres`、`sqlite`：`ExcludeKnowledgeIDs` 真正下推为 `NOT IN`。此前只有 ES/Milvus/Qdrant 等实现，默认 `RETRIEVE_DRIVER=postgres` 时拒绝集被静默丢弃。 |
| 13 种权限动作只有 `ask` 生效 | §2.2 动作分离 | `handler/knowledge.go` 的 `resolveKnowledgeAndValidateKBAction`：view / download 各走独立判定，ACL 查询失败即拒绝（fail-closed）。 |
| 外链不校验源文档当前权限 | §2.5 链接权限 ≤ 源文档 | `service/share_link_service.go`：创建时校验 `share` 动作，解析时重算密级/生命周期，提密或下架后活链接立即失效。 |
| 移动文档带走 ACL（静默提权） | §2.3 不得静默获得更宽权限 | 两条移动路径均重置文档级授权；新增 `GET /knowledge/:id/acl/move-preview` 输出"谁获得/失去访问"。 |
| 撤权只删一行，十个出口无失效机制 | §2.6 撤权传播 | 新增 `permission_versions`（租户/空间/文档三级 epoch）与 `revocation_propagations`（十个出口各一行处置结果）。缓存键含版本号，版本前进即失效。 |
| 派生知识权限不继承源证据 | §2.4 派生交集 | `service/derived_permission.go`：候选发布时继承源证据最严密级；引用无法解析则 409 拒绝发布。 |
| 列表泄露隐藏条目（标题/计数） | §2.10 存在性不泄露 | `KnowledgeListFilter.ExcludeKnowledgeIDs` + `MaxClassification` 下推到 SQL，total 计数同步收敛。 |

## 二、仍未完成

以下按章节列出，均为**没有对应实现**或**只有骨架**的部分。工作量从"接一根线"到"整块新功能"不等。

### 第 2 章 权限（剩余）

- **组织树 / 用户组 / 自定义人员集合**：ACL 主体只有 `user`；`group`/`role` 是预留列但没有解析器，也没有组织同步。
- **空间级与目录级 ACL**：ACL 只挂在文档上；`folder_path` 是派生字符串，不是策略节点，因此"目录单独授权 / 继承重算"无处落脚。
- **权限上限校验**：`subject ⊆ 父级`、动作上限、密级上限均未实现（只有密级参与检索判定）。
- **恢复继承 + 快照回滚 / break-glass**：无实现。
- **外链密码/验证码、服务端水印、匿名链接类型、访客身份与 NDA、季度盘点**：均未实现。当前只有 org/people 两种类型与访问日志。
- **会话历史重放复核**：历史消息引用不做二次权限校验。
- **审计动作缺口**：`view`/`search`/`download`/`export`/Agent 工具调用未进审计流；无异常检测（批量下载、非工作时间）；无等保/ISO 审计包导出；审计链无校验端点。

### 第 3 / 4 章 入库与组织（几乎整块）

- **自定义字段**：只有自由 JSON `CustomMetadata`，没有字段定义（类型/必填/默认值/校验/可见性）、没有召回字段、没有字段变更迁移任务。
- **模板中心**：不存在（故障案例/FAQ/SOP/会议纪要/项目复盘）。
- **业务系统连接器**：ERP/MES/PLM/QMS/OA/HR/CRM/项目系统**全部没有**；现有连接器是 Confluence、飞书、钉钉、语雀、Nextcloud、Seafile、GitLab、RSS、Notion。
- **企业微信连接器**：没有。
- **在线文档"关联而非复制"**：当前每次都重新拉取副本，没有权威源与编辑锁。
- **源删除处理**：直接物理删除，而不是"待确认下架"。
- **增量与对账**：有游标，但无 checksum 跳过、无事件版本乱序保护、无每日对账、无首次全量预览。
- **空间（Space）实体**：只有知识库，没有个人/团队/公共/项目/外部协作五种类型及其默认策略。
- **目录树**：深度上限 16，无拖拽排序、无封面/负责人、无目录模板、无空目录治理。
- **标签体系**：扁平标签，无公共/个人之分、无合并（只有改名）、无树状分类、无 Owner 与审批。
- **知识关联**：没有知识→知识关系表，没有"依据/替代/补充/冲突/前置/责任"类型化关系，没有反向链接与删除影响检查。
- **知识地图**：空间图/岗位图/新人路径均无。
- **批量迁移**：没有 Confluence 页面树 → 目录映射、没有版本与权限导入、没有"未审核"标识与分批补审。

### 第 5 章 内容协作（大部分）

- **@提及**（人/知识/专家）与通知：无。
- **点赞**：无表、无计数。
- **文档收藏**：收藏仅支持知识库与 Agent，不支持文档。
- **订阅**（空间/目录/知识/标签/作者/术语）与摘要订阅：无。
- **草稿自动保存与冲突合并**：无自动保存端点、无合并。
- **评论锚点随版本迁移**：未解决评论不进入审核清单。
- **版本diff / 回滚 / 语义化版本号**：只有递增版本号与快照，无差异对比、无回滚、无"主.次.修订"规则。

### 第 6 章 审核（剩余）

- **会签 / 或签 / 逐级 / 加签 / 转签 / 委托**：审批引擎只有单人/双人攒票。
- **14 类审核对象的其余 12 类**：官方答案、规则政策、权限提权、外部分享、删除下架、合并拆分、术语分类模板变更、模型/Prompt 上线、Agent 工具授权均未接入审批流；schema 提案与导出有各自独立的、无回执的状态机。
- **抽检**（100%/10%/2%）、审核员一致性、错误发布复盘、审核质量指标：均无。
- **审批凭证完整性**：回执缺审批人角色/部门/委托标记、四个时间戳、版本号、基线 ID、证据包 ID、意见正文。
- **特殊通道**：紧急发布后补审、快速下架、AI 生成内容标识、翻译版本复核、存量未审核标识均无。

### 第 7 章 生命周期（剩余）

- **变更单**：审批节点是空壳（`SubmitForApproval` 只改状态）；影响分析是"同 KB 同标签"近似；关闭门禁 4 条只实现 2 条；发布统一 `mark_stale`，不按变更类型分发。
- **变更信号**：内部事件、源系统状态、外部法规订阅、依赖链、连接器健康**全部没有**。
- **生效期**：`announce_at`/`expires_at` 存了但不生效；无过渡期双版本；**无 as-of 查询**。
- **复审周期**：只有单行 `review_cycle_days`（默认禁用），没有按知识类型的周期表（制度 6 个月、价格季度、案例 12 个月……），没有 Owner 空缺兜底链。
- **归档库**：无按需查询入口。
- **新鲜度降权**：检索时有状态过滤，但没有排序降权，也没有"待复审"提示注入答案。

### 第 8 / 9 / 10 / 11 章 本体 / 解析 / 沉淀 / 图（部分）

- **本体治理分级 L0–L4**：只有自由 JSON 配置，无枚举、无强治理触发（价格/合同/图纸/HR）。
- **引导补充信息**（领域范围/核心对象/典型流程/角色/关心信息/已有分类/例子）：只有 `domain` + `name` 两个输入。
- **迁移预演 / Schema 回滚 / 黄金集回归门禁**：均无。
- **图谱事实层未接入解析流水线**：`UpsertFacts`/`CreateCommit` 只有 handler 调用；抽取仍只写 Neo4j；证据非必填（违反"无证据不进正式图谱"）；`chunk_extraction_cache` 无读取方。
- **图算法**：无社区检测、无中心度（仅度数）、无专家发现。
- **GraphCommit**：无 diff、无灰度、无回放；`golden_gate_pass` 是调用方传入的布尔值。
- **经验沉淀**：无连接器与事件触发（只能手工 `POST /knowledge-candidates`）；无采集策略配置；无复用信号；候选发布后**不入 chunk/向量检索**。
- **L0–L3 门禁**：L0 语义未实现，无双人审核，无 SOP 冲突阻断，无"5 案例升级为 SOP"判定。
- **规则解析模式**：只有 LLM 抽取，无模板/正则规则通道。
- **音频说话人分离**：无；视频不支持；CAD 不支持。

### 第 12 / 13 章 检索与问答（剩余）

- **检索建议端点 / 历史 / 热门**：无（前端用 localStorage）。
- **拼音纠错 / 错别字纠正**：无（仅同义词扩展）。
- **符号索引**：无条款/段落/表格区域/步骤提取；无图号/物料号类型；`Locator` 恒为 NULL；未接入入库与删除钩子。
- **图谱通道未与其它三路融合排序**：它是独立阶段。
- **保存的视图（我的视图）**：无。
- **综合排序**（相关度+热度+权威+新鲜）：只有创建/更新时间/文件名。
- **推荐**：相关知识、猜你想学、最新动态、热门知识**全部没有**。
- **官方答案与规则知识（Policy-as-Code）**：整块没有。
- **答案标注依据版本+生效日期+最后验证时间**：无。
- **高风险问题引用覆盖率 100%**：无风险分类器，无覆盖率校验。
- **答案→知识 一键转换**：只有前端一句提示语，没有后端端点。
- **证据撤回后答案自动降级**：无。
- **Agent/MCP**：无 Evidence/Impact/Candidate 工具；无委托用户/目的/trace 字段；MCP 调用不写审计与证据包。

### 第 14 / 15 / 16 章 质量 / 阅读 / 运营（大部分）

- **健康分**：6 个维度只有 4 个（使用度是空占位，准确性缺失）；无按部门/领域的健康分。
- **质量指标**：及时性/准确性/价值三组指标无接口。
- **评测**：问答正确率、拒答正确率、越权召回率、过期误用率均无；黄金集只是检索评测。
- **黄金集门禁未接入任何发布动作**（`CheckGate` 无调用方）。
- **阅读页**：无自动目录、无沉浸模式、无阅读进度；无"已验证"徽章、无版本徽章、无 Owner 展示、无证据入口。
- **个人中心**：我的主页/我的知识/我的草稿/我的待办/我的关注均无；浏览历史仅前端 localStorage。
- **激励**：积分规则与文档不一致（浏览 +1 vs +0.1 等），无收藏/评论计分，无知识之星评选，无兑换。
- **学习路径**：无阶段模型、无认证、无岗位地图、无 SOP 变更联动、无考试关联、无前端。
- **问答社区**：整块没有。
- **看板**：总体/空间/搜索问答/趋势/治理/成本看板均无（搜索看板所需数据本轮已接上，但无读取界面）。
- **贡献排行**：只有积分榜。
- **系统管理后台**：无审批流设计器 UI、无水印/IP 限制、无备份恢复、无导入导出迁移工具。
- **开放平台**：无沙箱环境、无 API 版本弃用策略、无出站 Webhook（签名+重试）、无搜索框/知识卡片嵌入组件。
- **SSO**：有 OIDC，无 SAML、无 SCIM、无用户组同步。
- **模型与 Prompt**：`RecordUsage` 无调用方（用量台账空）；Prompt 版本不被加载器读取；无灰度、无回滚、无成本预算、无模型降级链；密级维度从不传入路由。

### 第 17 章 非功能

- 性能目标（搜索 P95 ≤ 500ms 等）无压测与门禁。
- 无灾备演练、无限流配额（仅 MCP/embed 有）、无成本分摊。
- 无多语言内容、无翻译版本与术语一致性。

## 三、建议的下一步优先级

原列的前六项（图谱事实层、符号索引、模型网关、审批六模式、自定义字段模板、官方答案、空间与目录权限、14 类审核对象）均已完成。剩余按"风险 × 可达性"排序：

1. **其余前端界面**：治理控制台已覆盖审批、官方答案、模板、目录权限、搜索质量与知识缺口（本轮）。仍未做界面的是：变更单、知识关联与知识地图、推荐与订阅、运营看板、个人中心、问答社区、学习路径认证。
2. **业务系统连接器**：ERP/MES/PLM/QMS/OA/HR/CRM 仍全部缺失。企业微信已补（本轮）。现有连接器：Confluence、飞书/Lark、钉钉、语雀、Notion、Nextcloud、Seafile、GitLab、RSS、IMA、企业微信。
3. **变更单剩余深度**：影响分析已改为沿关联图遍历（本轮）；仍无变更信号采集（内部事件/源系统/外部法规订阅）。

5. **推荐与订阅**：相关知识、猜你想学、最新动态、热门知识、订阅全部没有。

7. **激励与学习延伸**：积分兑换、SOP 变更自动派学习任务、考试题库关联、嵌入业务系统的即时推送均无。
8. **非功能**：压测门禁、灾备演练、成本分摊、多语言。
